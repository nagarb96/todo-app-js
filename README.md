# JavaScript To-Do App

A simple task manager built while practicing DOM manipulation and localStorage.

## 🔗 Live Demo
https://nagarb96.github.io/todo-app-js/

## 🛠 Tech Stack
HTML, CSS, JavaScript

## 🚀 Features
- Add and delete tasks
- Saves tasks in localStorage
- Tasks remain after page reload
- Minimal and clean UI

## ✅ What I Learned
- DOM manipulation
- Event handling
- Using localStorage
- Creating and removing elements dynamically
